Why it feels good

Built for craft, tuned for speed

Every interaction is GPU-driven and eased, so it reads as premium on a laptop and holds up on a phone — tilt included.

🪐

True depth parallax

A per-pixel depth map drives the shift, so foreground and background separate with real dimensionality — not a flat CSS tilt.

🖱️

Pointer, touch & tilt

Follows the cursor, tracks touch, and reads device orientation on mobile. Idle? A calm ambient sway keeps it alive.

📦

Genuinely drop-in

One <div>, one module script. Auto-mounts, supports multiple heroes per page, and tears down cleanly.

⚡

Offline & tiny

Three.js is vendored locally — no CDN, no tracking, no runtime network calls. Ships as static files.

🎚️

Live-tunable

Retune fill, framing, parallax and depth at runtime through a small API — the sliders above are wired straight to it.

♿

Respects the user

Honors prefers-reduced-motion, emits ready/error events, and degrades gracefully when textures fail to load.

Copy · paste · ship

Drop it into any page

Host the assets/, vendor/ and js/ folders alongside it, then paste the block below.

index.html 
<!-- 3D photo hero · 16:9 block -->
<div
  id="astro-hero"
  data-photo="./assets/photo.jpg"
  data-depth="./assets/depth.png"
  data-fill="0.55"
  data-center-y="0.57"
  style="width:100%; max-width:1600px; aspect-ratio:16/9;"
></div>

<script type="importmap">
  { "imports": { "three": "./vendor/three.module.js" } }
</script>
<script type="module" src="./js/astro-hero.js"></script>

16:9 block · self-contained · Three.js only · runs offline
